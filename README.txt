# MOHD ASLAM & CO. - Website Hosting Guide

## 1️⃣ Host on GitHub Pages
1. Go to https://github.com and login.
2. Create a new repository named `mohdaslamandco` (Public).
3. Upload both files: `index.html` and `logo-horizontal.png`.
4. Go to **Settings → Pages** → set Branch: `main` and folder `/ (root)` → Save.
5. Wait 1–2 minutes, then your site will be live at:
   `https://<your-username>.github.io/mohdaslamandco`

## 2️⃣ Host on Netlify
1. Go to https://app.netlify.com
2. Login → "Add new site" → "Deploy manually"
3. Drag and drop this entire ZIP (or extracted folder)
4. Your live link will appear like:
   `https://mohdaslamandco.netlify.app`

---
For any updates: Just re-upload the new files the same way.
